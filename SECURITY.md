# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 2.x | Bug and security fixes |
| 1.x | Security fixes until 2027-03-31 |
| < 1.4 | No |

## Reporting a vulnerability

Please report vulnerabilities **privately** through
[GitHub private vulnerability reporting](https://github.com/invelity/laravel-headless-wizard/security/advisories/new).
Do not open a public issue or discussion.

Include the affected version, a description of the impact and, if possible, a minimal reproduction.

## What to expect

- An acknowledgement within 3 working days.
- An assessment and a planned fix date within 10 working days.
- A coordinated release: the fix ships in a patch release, followed by a published GitHub security advisory that
  credits the reporter unless they prefer otherwise.
